# 👗 StyleSense

### Intelligent Fashion Recommendation & Search Platform

StyleSense is a full-stack fashion discovery platform that combines
product search, filtering, personalization, and recommendation ranking
to help users discover relevant products.

## ✨ Features

- 🔍 Intelligent product search
- 🎯 Personalized recommendations
- ❤️ Wishlist management
- 🛒 Cart management
- 👤 User authentication
- 📊 Interaction-based personalization
- 📱 Responsive interface

## 🧠 Recommendation System

StyleSense learns from user interactions such as:

View → Click → Wishlist → Cart

Different interaction types contribute different weights to the
personalization score.

The recommendation pipeline combines:

- Search relevance
- User preferences
- Interaction history
- Product popularity
- Product rating

## 🚀 Getting Started

### Clone the repository

git clone <your-repository-url>

### Install frontend dependencies

npm install

### Install backend dependencies

cd server
npm install

### Configure environment variables

Create your `.env` files with the required API and database
configuration.

### Run the application

Start the backend and frontend development servers.
